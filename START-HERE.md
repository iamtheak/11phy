# Start here — Physics 11

This is the complete React source from the published site, including the mobile layouts, electricity and optics sandboxes, tests, styles, extracted textbook content and original PDF. Dependencies and Git history are excluded. The archive has no GitHub account or hosting configuration attached.

## Run locally

Use Node.js 24 and pnpm. From this folder:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000 in your browser. Stop the server with Ctrl+C. After editing source, run `pnpm build` and refresh the page. The site uses hash routes, so it runs on any static hosting service.

## Main files

- app.jsx: React UI, routes, learning labs, direct manipulation and mass-drop sandbox
- content.mjs: chapters and physics models
- canvas.mjs: Canvas scenes and graphs
- animation.mjs / interactions.mjs: animation and dragging
- electrical.jsx / electricity.mjs: RC sandbox and circuit models
- optical-images.jsx / optics.mjs: lenses, mirrors and image formation
- responsive.jsx: phone layout and pointer-coordinate helpers
- dist/style.css: responsive styles (edit this file directly)
- dist/book.json / dist/source.pdf: textbook reading content and original PDF
- *tests.mjs / react-tests.jsx: model and React interaction checks

`dist/app.js` is generated by the build. The other files inside `dist/` are retained assets. Browser progress and notes are stored locally.

## Push to GitHub

Create an empty repository, then from this folder:

```sh
git init
git add .
git commit -m "Add Physics 11 React app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace the remote URL with your repository URL. See README.md for model assumptions and project details.
