# Physics 11 — product context

An interactive study companion to the uploaded CDC Nepal Grade 11 physics textbook. Students read source chapters, manipulate analytical diagrams, compare parameter changes and practice numerical answers. The book has 26 chapters, 78 analytical laboratories, 104 checked practice types and extracted source exercise cards.

Use scene: studying on desktop or a touch phone, often with sustained reading and repeated experimentation. The experiment, controls and equations should form one task. Reading and exercises must remain legible.

React 19, Canvas 2D, Pretext text layout and SVG drag controls. No backend or rigid-body engine. Notes and progress use the existing browser storage key. User-requested direct manipulation includes vectors, spring masses and a mass drop sandbox. Preserve routes, equations, chapters, notes and source PDF. Numerical practice can be checked; written source responses require self-assessment.

This design update uses Impeccable's typeset, layout and polish guidance. It refines the existing identity rather than changing textbook claims or physics.
